# 财智管家 MVP

一个面向个人和家庭的本地优先理财管理网站。当前版本覆盖账户、账单、预算、投资组合和财务目标，并使用浏览器 `localStorage` 保存数据。

## 运行

项目不依赖构建工具。在项目根目录启动任意静态服务器即可：

```powershell
python -m http.server 4173 -d dist
```

然后访问 `http://localhost:4173`。

## 当前能力

- 总资产、负债、净资产和月度现金流仪表盘
- 账户创建和资产分布统计
- 收入、支出、转账记录与筛选
- 分类预算和执行进度
- 投资持仓、收益和资产配置分析
- 财务目标创建与进度跟踪
- 数据导入、导出、主题切换和演示数据重置
- 响应式桌面端与移动端界面

## 数据说明

这是验证产品闭环的前端 MVP。数据只保存在当前浏览器中，不会上传到服务器。正式产品需要接入后端身份认证、PostgreSQL、加密、审计、备份和行情服务。

产品范围、迭代路线和验收标准见 [docs/MVP_PLAN.md](docs/MVP_PLAN.md)。
