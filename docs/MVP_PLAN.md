# 财智管家：产品方案与 MVP 实施记录

## 1. 产品定位

财智管家是一款个人与家庭资产管理工具，用于统一记录账户、收支、预算、投资持仓和财务目标，并通过清晰、可解释的指标帮助用户理解自己的财务状态。

第一阶段坚持以下边界：

- 不托管用户资金；
- 不代替用户执行交易；
- 不承诺收益；
- 不提供确定性的个性化投资建议；
- 第一版不接入银行卡和券商账户，采用手动录入与文件导入；
- 所有演示数据默认保存在浏览器本地。

## 2. 核心用户

- 希望集中查看现金、银行卡、信用卡和投资资产的职场人；
- 希望控制月度消费并建立储蓄习惯的用户；
- 需要跟踪家庭净资产、负债和中长期目标的家庭用户；
- 需要简单持仓与资产配置分析的个人投资者。

## 3. MVP 功能范围

### 3.1 仪表盘

- 总资产、总负债和净资产；
- 本月收入、支出、结余率；
- 净资产趋势；
- 预算执行概览；
- 账户概览与最近交易；
- 可解释的财务健康度提示。

### 3.2 账户与账单

- 创建现金、银行卡、储蓄、信用卡和投资账户；
- 录入收入、支出和账户间转账；
- 按交易类型、分类、备注进行检索；
- 账户间转账不计入收入或支出；
- 数据变更后自动刷新资产和现金流指标。

### 3.3 预算

- 维护月度分类预算；
- 显示已使用金额、剩余金额和执行比例；
- 对接近或超过预算的分类进行分级提醒。

### 3.4 投资组合

- 手动维护基金、股票、债券、存款等持仓；
- 计算持仓市值、成本、浮动盈亏和收益率；
- 展示资产类型分布和集中度提示；
- 当前价格由用户手动维护，后续版本接入授权行情源。

### 3.5 财务目标

- 创建应急储备、购房、教育、旅行等目标；
- 记录目标金额、已积累金额和目标日期；
- 展示进度、剩余金额和建议月投入。

### 3.6 数据与设置

- JSON 数据导出和导入；
- 浅色、深色主题；
- 恢复演示数据；
- 清晰提示本地存储边界。

## 4. 信息架构

```text
财智管家
├── 财务总览
├── 账户资产
├── 收支账单
├── 月度预算
├── 投资组合
├── 财务目标
└── 数据与设置
```

## 5. 当前技术方案

当前 MVP 使用原生 HTML、CSS 和 JavaScript：

- 无安装依赖和构建步骤；
- 使用语义化 HTML 和响应式 CSS；
- 使用 `localStorage` 做本地持久化；
- 使用原生 SVG 绘制净资产趋势；
- 使用 CSS `conic-gradient` 绘制资产配置图；
- 使用 JSON 文件完成数据备份和恢复。

选择静态架构是为了尽快验证用户是否愿意持续维护财务数据。在产品闭环验证后，迁移到 Next.js/NestJS 或 FastAPI，并接入 PostgreSQL、Redis、对象存储和任务队列。

## 6. 后续数据模型

正式服务端版本建议包含：

```text
users
user_sessions
accounts
transactions
transaction_categories
budgets
budget_items
securities
portfolios
positions
investment_trades
market_prices
financial_goals
notifications
audit_logs
```

金额必须使用定点数存储；证券价格、汇率和资产估值必须记录时间点；重要数据采用软删除和审计日志。

## 7. 安全与合规基线

正式上线前至少需要：

- HTTPS、强密码哈希、多因素认证和敏感操作二次验证；
- 数据传输、数据库和备份加密；
- 用户级数据隔离、后台角色权限和操作审计；
- 登录及敏感接口限流；
- 数据导出、删除、注销和授权撤回能力；
- 日志脱敏、密钥独立管理、备份恢复演练；
- 对数据来源、行情延迟和指标计算口径进行披露；
- 根据实际运营地区和商业模式完成专业合规评估。

## 8. 验收标准

- 新用户能在 3 分钟内创建账户并记录第一笔交易；
- 新增收入或支出后，账户余额和仪表盘指标即时更新；
- 转账不会错误计入月度收入或支出；
- 预算、投资和目标数据刷新后保持一致；
- 页面在桌面端和窄屏移动端均可正常操作；
- 刷新浏览器后数据不丢失；
- 导出的 JSON 可以重新导入并恢复状态；
- 站点无阻断性 JavaScript 错误。

## 9. 迭代路线

### V0.1：本地优先 MVP

完成上述闭环，验证信息架构、交互和核心计算。

### V0.2：账户与服务端

加入注册登录、云端同步、PostgreSQL、访问控制、审计和备份。

### V0.3：数据自动化

加入 CSV 智能映射、周期账单、邮件提醒和经授权的行情更新。

### V0.4：家庭与智能分析

加入家庭空间、多币种、可解释的财务健康报告和情景规划。

### V1.0：商业化

在完成安全审计和合规评估后，加入会员能力；涉及产品导流、投资建议、交易或资金托管的能力单独立项。
